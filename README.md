# Počítací hrdinové

Denní procvičování matematiky pro 2. a 4. třídu: 20 příkladů denně, body a hrdina, kterého si děti vylepšují. Až je hrdina na maximu, čeká na ně odměna od rodičů.

- `index.html` – celá aplikace (běží na GitHub Pages)
- `config.js` – adresa úložiště (Google Apps Script)
- `backend/Code.gs` – kód úložiště v Google tabulce
